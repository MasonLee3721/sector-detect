# H2：族群性即時偵測假設規格 v0.1

> 前身 H1（資金/領頭股領先同動性的預測假設）已於 2026-10-02 被 86 個波段的實證否證：
> D3 僅 41% 波段呈現正領先、D2 僅 51%（等同丟硬幣），且銳度與領先呈負相關。
> H2 轉向：不預測起漲，只即時偵測「族群性是否存在、有多強」。

## 1. 問題定義

使用者原始需求：「快速判斷族群性是否存在」。這是**偵測**問題（現在有沒有在發生），
不是**預測**問題（能不能提前知道）。H1 誤把偵測問題做成了預測問題。

H2 回答：「現在，哪個族群的族群性最強？」

## 2. 族群強度分數（Sector Strength Score, SSS）

每日對 38 族群計算：

```
SSS = z(D1) + z(D2) + z(D3)
```

其中 z(·) 為該維度相對自身過去 120 交易日的標準化分數（(x - mean) / std）。

- **D1**（同動性）：`co_move = 1 − 橫斷面離散度 / 平均個股時間序列波動`
- **D2**（資金集中度）：標準化(HHI20) + 標準化(5日總流入)
- **D3**（領先結構）：領頭股相對強度加速（`leader_accel`）

分數解讀：
- SSS > 3：三維度同時顯著高於歷史 → 強族群性
- 1 < SSS ≤ 3：中度族群性
- SSS ≤ 1：無明顯族群性（噪音）

另計**橫斷面排名**：每日 38 族群 SSS 排名，供日誌/儀表板使用（實務用，非檢定用）。

## 3. 可證偽假設

### H2a：偵測有效性

**宣稱**：SSS 高分期間，族群呈現真實的族群性（非隨機噪音）。

**操作化**：
- 高分期 = SSS 處於自身歷史 90 分位以上的日子
- 真實族群性 = 該期間族群內個股報酬的橫斷面同動性（D1 原始值）與波動率顯著高於低分期

**檢定**：
- 比較高分期 vs 低分期（SSS < 50 分位）的平均 D1 與平均絕對報酬
- H2a 成立條件：高分期的 D1 顯著高於低分期（t檢定 p < 0.05）

**否證條件**：高分期與低分期的 D1 無顯著差異，或高分期 D1 反而較低。

### H2b：動能延續性

**宣稱**：族群性強的族群，其超額報酬具有延續性。SSS 突破 90 分位後進場，
未來 20 個交易日的成本後超額報酬為正。

**操作化**：
- 進場訊號：SSS 首次突破自身 90 分位（前 20 日未在高位，避免重複計算）
- 持有：20 個交易日
- 報酬：族群等權還原報酬 − TAIEX 報酬 − 0.6% 來回成本

**檢定**：
- 彙總所有族群、所有進場訊號的成本後超額報酬
- H2b 成立條件：平均超額報酬 > 0 且 hit rate（正報酬比例）> 50%

**否證條件**：平均超額報酬 ≤ 0，或 hit rate ≤ 50%。

## 4. 與 H1 的關係

| 面向 | H1（已否證） | H2（本規格） |
|------|-------------|-------------|
| 問題 | 預測：資金/領頭是否領先同動 | 偵測：現在族群性有多強 |
| D2/D3 角色 | 領先指標 | 同期指標 |
| 訊號 | S_early（稀疏，3次/2.5年） | SSS 突破（預期頻繁得多） |
| 用途 | 試單時機 | 族群強度排名＋動能延續 |

## 5. 限制

1. SSS 的 120 日標準化窗口為暫定；短歷史族群（如新上市多的族群）標準化不穩。
2. H2b 的 20 日持有期為暫定；最適持有期需另做敏感度分析。
3. 本規格未處理「族群輪動」本身的預測（哪個族群**將要**變強），只處理當下偵測與動能延續。
4. 成本 0.6% 為散戶現股估計；法人成本較低，實際超額報酬可能略高。
