# SectorDetect — 台股族群性偵測

先判讀族群輪動或趨勢是否正在成形，再篩選可上車的標的。

> 本專案僅供個人研究與投資學習，不構成投資建議。

## 問題

1. **族群性是否存在？**——類股輪動或趨勢正在成形時，能否快速判讀出來，以利上車。
2. **全市場觀察是前提**——手選小宇宙有內建選擇偏誤，偵測不到新主題；必須看全市場才能有效辨別族群性。
3. **有效策略篩標的**——確認族群性之後，用可驗證的規則篩選可觀察／可上車的標的。

## 設計

- **兩階段框架**：族群性偵測 → 標的篩選。偵測不到族群性，就不進篩選。
- **族群性三維度**（皆為「一群股票在一段時間內」的屬性）：
  - D1 同動性：族群內報酬離散度是否收斂＋群體同向移動
  - D2 資金集中度：族群內法人淨流入的 HHI、前三名佔比
  - D3 領先落後結構：領頭股相對強度加速是否領先廣度擴散
- **分層訊號**（確信度階梯，非二元上車／不上車）：
  - S_early：資金集中度上升＋領頭 RS 加速 → 試單區
  - S_mid：廣度擴散＋站上均線＋離散度收斂 → 加碼區
  - S_confirm：均線多頭排列＋帶量突破 → 持有區
- **核心假設 H1**：族群內法人資金集中度上升，領先價格同動性收斂；以此為早期訊號的族群，未來 20 個交易日有成本後超額報酬。

## 與 FundFlo 的分工

- FundFlo：38 族群每日資金排名日報（生產中）。
- SectorDetect：驗證排名靠前族群的族群性真偽＋掃描籃子外的新萌芽主題。
- 族群分類以 38 族群籃子為 single source of truth。
